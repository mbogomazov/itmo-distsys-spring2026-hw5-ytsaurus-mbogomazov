# Домашнее задание 5: YTsaurus и MapReduce 

## Обязательно напишите ФИО в свой PR!!!

## Описание

Это домашнее задание посвящено знакомству с платформой для хранения и обработки больших данных
YTsaurus и MapReduce-задачами.

## Задание 

1. Разверните локальную инсталляцию YTsaurus (см. [инструкцию](https://ytsaurus.tech/docs/ru/overview/try-yt))

2. Напишите код или CLI-команду (с использованием клиентских библиотек YTsaurus или YTsaurus CLI) для создания динамической таблицы `//home/ваше-имя`. В схеме таблицы должен присутствовать составной (из нескольких колонок) ключ. Напишите код/CLI-команду для добавления строки в таблицу и для чтения ее по ключу.

3. Выберите свой любимый текстовый документ (например, книгу) в plain-text формате и сохраните его. Обратите внимание, что для следующего задания хороший текст должен состоять из множества строк (а не строк, в которых записаны длинные абзацы). Воспользуйтесь [официальным туториалом](https://ytsaurus.tech/docs/ru/overview/try-yt#mr), чтобы посчитать в вашем документе количество слов
с помощью уже разработанной MapReduce-задачи.

4. Разработайте на основе существующей MapReduce-задачи свою, которая построит в отдельной таблице поисковый индекс встречающихся слов вида `(слово, [номер строки 1, номер строки 2, ...])`.
Вам могут пригодиться [примеры кода на python для работы c ytsaurus](https://github.com/ytsaurus/ytsaurus/tree/main/yt/python/examples).

5. Напишите YQL-запрос, который по построенной вами таблице в п. 4 и фиксированному номеру строки (например, 7) выводит все слова (из этой же таблицы), которые строка содержит.

## Критерии оценки

Результаты работы необходимо оформить в виде отчета [`REPORT.MD`](./REPORT.MD) в свободной форме (по заданиям), в которых необходимо зафиксировать все артефакты, которые вы создали в рамках задания, т.е. подтверждения выполнения заданий.

```plain
Пожалуйста, ссылайтесь на файлы в вашем репозитории, в вашем отчете с помощью ссылок (как в примере с REPORT.MD выше)!
```

Когда можно будет проверять работу, замените в файле `READY_TO_CHECK.TXT` слово `NO` на `YES`. Тогда ваша галочка в CI/CD будет зеленая, и можно будет проверять работу.

Обратная связь будет в виде комментариев в ветке PR Feedback.

| Критерий и требуемые артефакты | Баллы |
|----------|-------|
| Развертывание YTsaurus – скриншот с директорией, названной вашим именем | 1 |
| Динамическая таблица - три программы/скрипта (и результат их выполнения: скриншот и вывод CLI) | 2 |

| Word Index 2: YQL-запрос и результат его выполнения | 2 |
| **Итого** | **10** |
